# Costa Corretor

Esta versão do projeto utiliza **React** com **Vite** para permitir o gerenciamento de postagens de imóveis.

## Desenvolvimento

1. Instale as dependências (é necessário ter o Node instalado):
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. A aplicação ficará disponível em `http://localhost:5173` por padrão.

## Gerenciamento de Imóveis

O projeto inclui um componente simples que permite cadastrar, listar e remover imóveis em memória. É apenas um exemplo de como o gerenciamento pode ser implementado.

O arquivo `legacy-index.html` contém a página estática original antes da refatoração.
